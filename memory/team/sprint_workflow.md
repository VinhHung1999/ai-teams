Sprint completion order: done → bug fix → merge main → close sprint → retro

1. Finish work, tasks move to **done**
2. Wait and test for bugs
3. Fix all bugs found
4. Merge code to **main** branch
5. **Close/complete the sprint**
6. Quick retro

**Why:** Ensure no bugs ship to main. Sprint only closes after code is stable and merged.

**How to apply:** Don't rush to merge or close sprint. Wait for user to confirm bugs are fixed before merging to main. Don't close sprint until merge is done.
