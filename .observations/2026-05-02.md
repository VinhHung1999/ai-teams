**Assistant:**

⚠️ Bad news — Claude bắt **UUID hợp lệ**, không nhận arbitrary string như `ai_teams-PO`.

**2 workaround:**

**(a) UUID v5 deterministic** — hash `<session>-<role>` qua namespace cố định → cùng input luôn ra cùng UUID
```js
const NAMESPACE = '6ba7b810-9dad-11d1-80b4-00c04fd430c8';
sessionId = uuidv5(`ai_teams-PO`, NAMESPACE);
// → '7a9e...' luôn cố định, backend tính lại được
```

**(b) Map file** ⭐ — `setup-team.sh` gen UUID rồi ghi `.ai-teams-sessions.json` ở project root
```json
// /Users/hungphu/Documents/AI_Projects/ai-teams/.ai-teams-sessions.json
{ "PO": "abc-123-...", "DEV": "def-456-..." }
```
Backend đọc file này → biết file JSONL của từng role.

**So sánh:**

| | (a) UUID v5 | (b) Map file |
|---|---|---|
| Need shared constant | namespace UUID phải sync giữa script + backend | không cần |
| Restart pane | cùng UUID auto | đọc file → cùng UUID |
| Manual edit | khó (phải tính lại) | dễ (sửa JSON) |
| Migrate existing teams | recompute UUID | gen 1 lần lưu lại |

**Em recommend (b) Map file** — đơn giản, dễ debug, không cần shared constant. Setup script làm 1 lần, backend chỉ `fs.readFile` rồi map role→file.
